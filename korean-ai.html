공개 프로젝트 k-skill을 처음 보는 분을 위한 안내. 2026년 10월 4일 확인한 개발자 문서에는 125개 스킬이 정리되어 있습니다. 깨비AI가 만든 도구가 아니라, NomaDamas가 공개한 프로젝트를 소개하는 자료입니다.

무엇을 준비하나요?

스킬을 설치하고 실행할 수 있는 AI 에이전트 환경이 필요합니다. 개발자는 Claude Code, Codex 등의 지원을 안내합니다. 일반 채팅창에 질문만 붙여 넣는 것과는 다릅니다. Node.js 18 이상과 npx가 기본이며, KTX 시간표에는 Python 3.11 이상과 uv도 필요합니다.

처음에는 이 문장부터

https://github.com/NomaDamas/k-skill 의 README와 설치 문서를 읽어줘. 내가 쓰는 환경에서 seoul-density 기능을 이용하려면 무엇이 필요한지 먼저 설명해줘. 필요한 스킬과 공통 설정만 준비하고, 추가 인증이 필요하면 알려줘. 설정이 끝나면 강남역 혼잡도를 기준 시각과 함께 조회해줘.

위 문장은 시작 요청의 예시입니다. 설치 도중 선택이나 설정이 필요할 수 있습니다. 문서의 기본 권장 방식은 전체 설치 후 공통 설정이며, 조회 기능만 선택 설치하는 경로도 제공합니다.

비용과 데이터는 구분해서

스킬 모음은 무료 공개 프로젝트입니다. 사용하는 AI 서비스의 요금과 기능별 외부 서비스 조건까지 모두 무료라는 뜻은 아닙니다. 공개 프록시를 거치는 기능도 있으므로, 해당 기능 설명을 보고 필요한 입력만 제공하세요.

바로 요청해볼 질문 3개

1. 나가기 전, 서울 혼잡도

seoul-density로 지금 강남역 혼잡도와 추정 인구 범위를 조회해줘. 데이터 기준 시각을 꼭 적고, 조회 실패 시 추측하지 말아줘.

주요 121개 장소가 대상입니다. 인구는 통신 신호 기반 추정치이며 실시간과 시차가 있습니다. 새벽이나 호출량 제한 등으로 응답하지 않을 수도 있습니다.

2. 노트북 가격을 비교할 때

danawa-price-search로 맥북 에어 M4 13인치 16GB/256GB 모델을 찾아줘. 같은 모델·사양끼리 배송비 포함 금액을 비교하고, 카드·쿠폰 등 조건부 가격은 별도로 표시해줘. 결제는 하지 마.

쇼핑몰 표시 가격을 비교하는 용도입니다. 다른 사양이 섞이지 않았는지 확인하고 실제 판매처의 재고·결제 금액을 다시 보세요. 깨비AI가 이 가격 조회 기능을 직접 실행한 것은 아닙니다.

3. 서울→부산 KTX 계획 시간표

railway-timetable로 2026년 10월 10일 오전 8시부터 12시 사이 서울 출발, 부산 도착 KTX 계획 시간표를 찾아줘. 출발·도착 시각과 열차번호를 표로 정리하고, 조회한 시간표의 기준도 알려줘.

코레일 공식 공개 계획 시간표 조회용입니다. 실시간 지연·운휴·잔여석은 제공하지 않으며 예약·결제도 하지 않습니다. 최종 운행 정보와 예매는 코레일에서 확인하세요.

깨비AI가 직접 확인한 범위

2026년 10월 4일 공개 혼잡도 프록시에서 강남역 응답을 확인했습니다. 응답 기준 시각은 18:35 KST, 혼잡도는 보통, 추정 인구는 62,000~64,000명이었습니다. 이 숫자는 당시 데이터이며 현재 상태를 보장하지 않습니다.

이는 공개 조회 경로의 응답 확인입니다. 독자의 컴퓨터에 스킬을 설치해 전체 흐름을 검증한 것은 아닙니다. 가격 비교와 철도 시간표는 개발자 문서를 확인해 정리했습니다.

원하는 결과가 안 나올 때

설치 여부 → 기능 이름 → 추가 설정 → 입력값 → 원본 서비스 응답 순으로 확인하세요. 답이 없는데 AI가 숫자를 만들어내지 않도록 “실패하면 실패했다고 알려줘”를 요청에 붙이면 좋습니다.
